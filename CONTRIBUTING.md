# Contribution rules

Contributions to this codebase are welcome under the following conditions:

1. You've signed the required CLA.
1. If you want some new functionality or a big rework, start with an issue. Describe why you want it and how you think it fits the existing approach.
1. AI-written code is OK. AI-written communication is not. The communication should be fully human-written. Communication is everything that is not code: PR and issue titles, descriptions, comments, etc.
1. You are open to addressing feedback.
1. Any security vulnerability should be disclosed through our [vulnerability disclosure program](https://snowplow.io/vulnerability-disclosure-program).
